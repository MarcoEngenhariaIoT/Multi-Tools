# Multi Tools

Ferramenta utilitária para manutenção e reparo de sistemas Windows, desenvolvida com base no projeto de ENG0800. O Multi Tools reúne funcionalidades essenciais para diagnóstico, otimização e correção de problemas comuns em notebooks e PCs.

## Funcionalidades

- Criação de pontos de restauração do sistema
- Correção de imagem de implantação (DISM)
- Verificação e correção de arquivos do sistema (SFC)
- Ativação de configurações de alto desempenho
- Gerenciamento da central de notificações do Windows
- Ativação de licenças Windows e Office (via script auxiliar)
- Assistente de restauração do sistema
- Verificação e desativação do BitLocker
- Instalação de drivers
- Limpeza de arquivos temporários

## Requisitos

- Sistema operacional Windows 10 ou superior
- Permissões de administrador para execução plena
- PowerShell habilitado

## Como usar

Execute o arquivo `Multi Tools` como administrador e selecione a opção desejada no menu interativo.
